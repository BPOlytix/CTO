# Accrue AI - Backend

Accrue AI is a fully automated, GAAP-compliant AI bookkeeping agent that integrates deeply with Xero.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

### Project Structure

- `src/api`: API routes and controllers.
- `src/services`: Business logic and external integrations (e.g., Xero).
- `src/models`: Database models and types.
- `src/config`: Configuration files.
- `src/utils`: Helper functions.

### Scripts

- `npm start`: Run the application using `ts-node`.
- `npm run build`: Compile TypeScript to JavaScript.
- `npm run lint`: Lint the codebase.
- `npm run format`: Format the codebase using Prettier.
